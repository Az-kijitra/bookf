# bookf ユーザーマニュアル (0.1.0)

`bookf` は、読んだ本を記録する Windows 10 / 11 用のアプリです。タイトルや ISBN から書誌情報と表紙を補い、評価・読了日・感想をキーボードで素早く記録できます。

---

## 1. インストール

1. [Releases](https://github.com/Az-kijitra/bookf/releases) から `bookf_0.1.0_x64-setup.exe` をダウンロードします。
2. ダウンロードしたファイルを実行し、画面の案内に従います。インストール先は既定で `%LOCALAPPDATA%\bookf` です（現在のユーザーだけ。管理者権限は不要です）。
3. スタートメニューの「bookf」から起動します。

Microsoft Edge WebView2 ランタイムが無い PC では、インストーラーが取得して導入します（Windows 11 には標準で入っています）。

### 1.1 SmartScreen の警告

インストーラーにはコード署名がないため、「Windows によって PC が保護されました」と表示されることがあります。その場合は「詳細情報」を選び、表示される「実行」を押してください。

ダウンロードしたファイルが壊れていないかは、Releases にある `bookf_0.1.0_x64-setup.exe.sha256` の値と、PowerShell の `Get-FileHash .\bookf_0.1.0_x64-setup.exe` の結果（大文字小文字は無視）を比べて確かめられます。

---

## 2. アンインストール

Windows の「設定」→「アプリ」→「インストールされているアプリ」から「bookf」を選んでアンインストールします。

アンインストール画面の「アプリのデータを削除する」は既定でオフです。

- **オフのまま**: 記録（データベース・表紙・設定）は残り、再インストールすると引き継がれます。
- **オンにする**: `%APPDATA%\dev.bookf.app` の中身（既定の場所のデータベース・表紙・バックアップ・設定）を削除します。

同期フォルダーなど別の場所に移したデータベースは、どちらの場合も削除されません。

---

## 3. データの保存場所

| 内容 | 場所 |
|---|---|
| データベース（既定） | `%APPDATA%\dev.bookf.app\books.db` |
| 表紙画像 | データベースと同じフォルダーの `covers\` |
| 自動バックアップ | データベースと同じフォルダーの `books_backup.json` |
| 設定 | `%APPDATA%\dev.bookf.app\settings.json`（データベースの場所だけ） |

今開いているデータベースの場所は、ステータスバーの右端に表示されます。

## 4. 画面と基本操作

```
┌ メニューバー ───────────────────────────────────────────────┐
│ 検索バー                                                     │
├ 絞り込み ─┬ 本（書籍一覧）────────────────┬ 詳細 ────────────┤
│ すべて    │ 評価 タイトル 著者 種別 状態 読了日│ 表紙・タイトル・★ │
│ ステータス│                                │ 著者・状態・日付… │
│ 種別      │                                │ 感想・メモ        │
│ 評価      │                                │                   │
│ 読了年    │                                │                   │
├───────────┴────────────────────────────────┴───────────────────┤
│ ステータスバー: 位置 / 件数・読了数 / 平均評価 / メッセージ / DB│
└────────────────────────────────────────────────────────────────┘
```

フォーカスのある枠は明るい水色の線で囲まれます。`Tab` でサイドバーと書籍一覧を行き来します。

### 4.1 メニューバー

`Alt` を押しながら括弧内の文字を押すと、そのメニューが開きます（`Esc` で閉じる）。

| メニュー | 項目 |
|---|---|
| ファイル (F) | 本を追加 (`Ctrl+N`)、Notion CSV 取り込み… (`Ctrl+I`)、データベースを開く… (`Ctrl+O`)、保存先を移動… |
| 編集 (E) | 書誌情報を検索… (`u`)、リンク先から書誌情報を取得、表紙画像を変更…、リンクを開く (`o` / `Enter`)、本を削除 (`Delete`) |
| 表示 (V) | 並び替え: 読了日 / タイトル / 著者 / 評価、昇順・降順の切り替え (`r`)、すべての絞り込みを解除 |

本を選んでいないときやリンクが無いときは、使えない項目が淡く表示されます。

### 4.2 絞り込みと検索

- **サイドバー**: 「すべて」「ステータス」「種別」「評価」「読了年」の値を選ぶと、その本だけを表示します。数字は件数です。`j` / `k` で移動すると、すぐに絞り込みが変わります。
- **検索バー** (`/` または `Ctrl+F`): 入力した語をすべて含む本に絞り込みます。空白で区切ると複数の語で絞り込めます。タイトル・サブタイトル・著者・出版社・感想・ISBN が対象で、大文字小文字と全角半角は区別しません。`Enter` または `↓` で先頭の本を選んで一覧へ戻ります。
- サイドバーと検索は組み合わせて使えます。両方を解除するには「表示」→「すべての絞り込みを解除」。

### 4.3 並べ替え

列見出しをクリックするか、`s` で並べ替えの項目を順に切り替えます。同じ列をもう一度クリックするか `r` を押すと、昇順と降順が入れ替わります。

- 読了日と評価は、新しい順・高い順から始まります。読了日の無い本は、開始日で並び、どちらも無い本は常に最後です。
- タイトル・著者・種別・状態は、日本語の順で昇順から始まります。

### 4.4 詳細パネル

右側に、選んでいる本の情報が表示されます。各欄は直接書き換えられ、別の欄へ移ると保存されます。

| 欄 | 説明 |
|---|---|
| 表紙 | クリックすると表紙の変更ダイアログ（§5.5）が開きます。 |
| タイトル・★ | ★をクリックすると評価が変わります（一覧で `1`〜`5`、`0` でも可）。 |
| 状態 | 「読了」にしたとき読了日が空なら今日の日付を、「読書中」にしたとき開始日が空なら今日の日付を入れます。 |
| 種別 | 書籍、書籍（図書館）、Kindle、Kindle Unlimited、オーディブル、学術誌、記事、ほか取り込んだ値。 |
| 開始日・読了日 | 日付の入力欄です。 |
| 出版社・出版日・ISBN | 書誌情報の検索で入りますが、手でも書き換えられます。 |
| リンク | ↗ で既定のブラウザーで開きます。 |
| 感想・メモ | `e` で編集を始め、`Ctrl+S` またはほかの欄へ移ると保存します。`Esc` で一覧へ戻ります。 |

### 4.5 本の削除

一覧で `Delete`（または「編集」→「本を削除」）を押し、確認ダイアログで「削除」を選びます。保存していた表紙画像も削除されます。

## 5. 本を追加する・書誌情報を補う

### 5.1 本を追加する

1. `Ctrl+N`（「ファイル」→「本を追加」）で「本を追加」ダイアログを開きます。
2. タイトル・著者名・ISBN・URL のどれかを入れて `Enter` で検索します。
3. `↑` / `↓` で候補を選び、下の「状態」と「種別」を選んで、`Enter`（または「追加」）で登録します。

検索で見つからない本は、「手動で追加」で入力した文字をタイトルにして登録できます。

### 5.2 検索のしくみ

| 入力 | 動作 |
|---|---|
| ISBN（10 桁または 13 桁、ハイフン可） | openBD で書誌情報と書影を引き、無ければ CiNii Books で探します。 |
| タイトル・著者名 | CiNii Books で探します。見つからないときは、空白で区切った 1 語目をタイトル、2 語目を著者として探し直します。 |
| URL | §5.3 のリンク先からの取得を行います。 |

候補の書影は、openBD・Google Books・Amazon の画像を使います。

### 5.3 リンク先から書誌情報を取得する

本にリンクが登録されていれば、「編集」→「リンク先から書誌情報を取得」、または検索ダイアログの「🔗 リンク先から取得」で、リンクから書誌情報を補えます。

- **一般の Web ページ**: ページのタイトル・画像・著者のメタ情報（OGP）を読みます。
- **Amazon / Audible の URL**: bookf はこれらのページを読みに行きません。URL に含まれる ASIN / ISBN とタイトルの部分だけを使い、ISBN が分かれば openBD と CiNii Books で正式な書名・著者・出版社を補います。紙の本の URL（`/dp/` の後が数字 10 桁）ならたいてい補えますが、Kindle や Audible の本（`B0` で始まる番号）では、書影と URL 中のタイトルしか取れません。

### 5.4 書誌情報を更新する

一覧で `u`（「編集」→「書誌情報を検索…」）を押すと、その本の ISBN（無ければタイトル）で検索した状態のダイアログが開きます。候補を選んで「この内容で更新」を押すと、候補にある値で上書きします。検索で見つからず、本にリンクがあるときは、リンク先からの取得を試します。

登録済みのリンクは上書きしません（Audible の版など、正確なページを指していることが多いためです）。

### 5.5 表紙を変える

詳細パネルの表紙をクリックするか、「編集」→「表紙画像を変更…」で、表紙の変更ダイアログを開きます。

1. **PC 内の画像ファイルから読み込む**: PNG / JPG / WebP / GIF の 10 MB までの画像を選びます。
2. **任意の画像 URL から読み込む**: 画像の URL を入れて読み込みます。
3. **現在の表紙を削除する**: 表紙を外します。

表紙はデータベースと同じフォルダーの `covers\` に保存されるので、オフラインでも表示されます。

## 6. キー割り当て

ダイアログを開いている間と、日本語入力で変換している間は、メイン画面のキー操作は働きません。入力欄にいる間は、`Ctrl` の組み合わせと `Esc` 以外のキーは文字の入力になります。

### 6.1 どこでも

| キー | 動作 |
|---|---|
| `Ctrl+N` | 本を追加 |
| `Ctrl+I` | Notion CSV を取り込む |
| `Ctrl+O` | データベースを開く |
| `Ctrl+F` / `/` | 検索バーへ |
| `Tab` | サイドバー ⇔ 書籍一覧 |
| `Esc` | 入力欄から抜けて書籍一覧へ |
| `Alt` + `F` / `E` / `V` | メニューを開く |

### 6.2 検索バー

| キー | 動作 |
|---|---|
| `Enter` / `↓` | 先頭の本を選んで書籍一覧へ |

### 6.3 サイドバー

| キー | 動作 |
|---|---|
| `j` / `↓`、`k` / `↑` | 絞り込みの項目を移動 |
| `Enter` / `l` / `→` | 書籍一覧へ |

### 6.4 書籍一覧・詳細パネル

| キー | 動作 |
|---|---|
| `j` / `↓`、`k` / `↑` | 次 / 前の本 |
| `PageDown` / `PageUp` | 1 画面分移動 |
| `g` / `Home`、`G` / `End` | 先頭 / 末尾 |
| `h` / `←` | サイドバーへ |
| `1`〜`5` | ★評価を付ける |
| `0` | 評価を消す |
| `Enter` / `o` | リンクをブラウザーで開く（ダブルクリックでも可） |
| `e` | 感想・メモを編集（`Ctrl+S` で保存） |
| `u` | 書誌情報を検索して更新 |
| `s` | 並べ替えの項目を切り替え（読了日 → タイトル → 著者 → 評価 → 種別 → 状態） |
| `r` | 昇順・降順を反転 |
| `Delete` | 本を削除（確認あり） |

### 6.5 書誌情報の検索ダイアログ

| キー | 動作 |
|---|---|
| `Enter` | 検索語を変えたときは検索、そうでなければ選んでいる候補で追加・更新 |
| `↑` / `↓` | 候補を移動（ダブルクリックでも選べます） |
| `Esc` | 閉じる |

## 7. 同期フォルダーで使う・Notion から移行する

### 7.1 Google ドライブなどで共有する

1. 「ファイル」→「保存先を移動…」で、同期フォルダーの中の保存先（例: `G:\マイドライブ\読書記録\books.db`）を指定します。
2. そこにまだファイルが無ければ、今のデータベースと表紙がコピーされ、以後はそのファイルを使います。すでにファイルがあれば、コピーせずにそのファイルを開きます。
3. 別の PC では、「ファイル」→「データベースを開く…」(`Ctrl+O`) で同じファイルを選びます。

選んだ場所は記憶され、次に起動したときもそこを開きます。元の場所のファイルは削除されません。

**注意**

- 同じデータベースを 2 台の PC で同時に開いて編集しないでください。使う PC を替える前に、同期が終わっていることを確かめてください。
- 起動したときに同期フォルダーが見つからない（ドライブが未接続など）と、既定の場所のデータベースを開きます。ステータスバー右端のパスで、どちらを開いているか確かめられます。同期フォルダーが使えるようになったら、bookf を起動し直してください。

### 7.2 Notion から移行する

1. Notion の読書リストのデータベースを開き、「…」→「エクスポート」で形式に「Markdown と CSV」を選んで書き出し、ZIP の中の CSV を取り出します。
2. bookf で「ファイル」→「Notion CSV 取り込み…」(`Ctrl+I`) を選び、CSV を指定します。

| CSV の列 | 取り込み先 |
|---|---|
| `タイトル`（必須） | タイトル |
| `著者` | 著者 |
| `ステータス` | 状態（空なら「未着手」） |
| `種別` | 種別（空なら「書籍」） |
| `評価` | ⭐ の数（または数字 0〜5） |
| `読了日` / `開始` | `2024年6月16日` などの日付 |
| `リンク` | リンク（Amazon の URL なら ISBN も取り出します） |
| `ISBN` | ISBN |
| `感想` または `メモ` | 感想・メモ |

- 同じタイトルと著者の本がすでにあれば、取り込まずに飛ばします。何度取り込んでも重複しません。
- 取り込み後、ステータスバーに「n 件を追加、m 件をスキップ」と表示されます。
- 取り込んだ本の書影や出版社は、本を選んで `u` で検索して補えます。

## 8. バックアップと復元

データベースを開くたびに（起動時と保存先を切り替えたとき）、全書籍を `books_backup.json` に書き出します。書籍が 1 冊も無いときは書き出さないので、空のデータベースで良いバックアップが消えることはありません。

同期の競合などでデータベースが壊れたときは、次の手順で戻せます。

1. bookf を終了します。
2. データベースのフォルダーにある `books.db` を別の名前（例: `books.broken.db`）に変えます。同期クライアントが作った競合ファイル（`books (1).db` など）があれば、それも退避します。
3. 退避したファイルのうち新しい方を `books.db` に戻して bookf を起動し、内容を確かめます。
4. どのファイルも使えないときは、`books_backup.json` を保管しておき、問題を [Issues](https://github.com/Az-kijitra/bookf/issues) で知らせてください（JSON からの復元機能は今後の候補です）。

日ごろの備えとしては、データベースのフォルダーごと（`books.db`、`covers\`、`books_backup.json`）を別の場所にコピーしておくのが確実です。

## 9. 困ったとき

| 症状 | 対処 |
|---|---|
| 検索しても見つからない | 語を短くする、ISBN で検索する、著者名を外すなどを試してください。CiNii Books に無い本（雑誌・同人誌など）は「手動で追加」で登録できます。 |
| 「通信に失敗しました」と出る | インターネットへの接続を確かめてください。プロキシやファイアウォールが `ci.nii.ac.jp`・`api.openbd.jp`・`books.google.com`・`images-na.ssl-images-amazon.com` への接続を止めていないか確かめてください。 |
| 表紙が表示されない | 取得元に書影が無いことがあります。「表紙画像を変更」で画像ファイルか URL を指定してください。「画像ではありません」と出るときは、その URL が画像そのものを指していません。 |
| Amazon のリンクからタイトルが取れない | Kindle / Audible の本では URL から ISBN が分からないためです。タイトルで検索してください（§5.3）。 |
| 記録が消えたように見える | ステータスバー右端のパスを確かめてください。同期フォルダーが見つからず、既定の場所のデータベースを開いている可能性があります（§7.1）。 |
| 「データベースを開けません」と出る | ファイルが同期中か、別のアプリが開いている可能性があります。少し待って開き直してください。直らないときは §8 の手順で戻してください。 |
| 起動時に SmartScreen の警告が出る | §1.1 を参照してください。 |

問題の報告や要望は [GitHub の Issues](https://github.com/Az-kijitra/bookf/issues) にお寄せください。
