# SPEC-0100-0001: プロダクトコンセプトとスコープ

| 項目 | 内容 |
|---|---|
| Spec ID | SPEC-0100-0001 |
| 領域 | 0100 プロダクト方針 |
| 親 | 領域ルート |
| ステータス | 有効 |
| 最終更新 | 2026-11-06 |
| 関連 Issue | ISS-0001 |

## 1. 背景

読書の記録を Notion のデータベースで管理していたが、次の不満があった。

- 書名・著者・ISBN・表紙を毎回手で入力する手間が大きい。
- Web アプリなので、起動と操作がキーボードだけでは素早くできない。
- データが Notion に閉じていて、ファイルとして手元に持てない。

## 2. 目的

| ID | 目的 |
|---|---|
| R-01 | **入力負担の解消**: 書名・著者名・ISBN・URL のどれかを入れるだけで、正式な書誌情報と表紙を補完する（SPEC-0300-0003）。 |
| R-02 | **素早い操作**: `guif` と同じ外観（Nord 配色・等幅フォント・細線枠）と、キーボードだけで閲覧・記録できる操作体系（SPEC-0300-0001）。 |
| R-03 | **データを手元に**: 記録は 1 つの SQLite ファイル。同期フォルダーに置けば複数の PC で共有できる（SPEC-0300-0004）。 |
| R-04 | **既存データの継承**: Notion から書き出した CSV を取り込める（SPEC-0300-0002）。 |

## 3. スコープ

### 3.1 対象

- Windows 10 / 11（64 ビット版）のデスクトップアプリ。
- 1 人の利用者が、自分の読書を記録する用途。
- 日本語の書籍（書誌情報の取得元は日本の公開サービス）。画面の文言は日本語。

### 3.2 対象外

- 複数人での同時編集、サーバーやアカウントを使う同期（同期はクラウドストレージのクライアントに任せる）。
- 書籍の購入・貸出の管理、読書時間の計測。
- macOS / Linux / スマートフォン（将来候補は SPEC-0900-0001）。
- 外部サイトのページから情報を取り出すために、ブラウザーを装ったり検知を回避したりすること（ISS-0002）。

## 4. 製品名

`bookf`（すべて小文字）。実行ファイル名・インストーラー名・識別子 (`dev.bookf.app`) にも使う。
