## 1. 背景と目的

現在 Notion で管理している読書履歴において、以下の課題を解決する。
1. **入力負担の解消**: 書籍名（またはISBN）を入れるだけで、正式タイトル・著者・ISBN・表紙・Amazonリンクを自動補完する。
2. **クラウド共有 & マルチデバイス**: Google ドライブ等のクラウドストレージ同期フォルダにデータベースファイルを置き、PC・スマホ双方からアクセス可能にする（まずはPC版を完成）。
3. **高速・軽快な操作性**: `guif` と同じ Nord テーマ、1px ボーダー、等幅フォントを採用し、キーボード操作で素早く閲覧・記録できる。
4. **既存データの継承**: Notion からエクスポートした CSV を無損壊でインポートできる。

- **配色テーマ**: Nord テーマ（`guif` のプリセットと同一）

### 2.3 キーボードショートカット
**全体**

| キー | 動作 |
|---|---|
| `Ctrl + N` | 本を追加（書誌情報の検索ダイアログを開く） |
| `Ctrl + I` | Notion CSV を取り込む |
| `Ctrl + O` | データベースを開く |
| `/` or `Ctrl + F` | 検索バーにフォーカス（インクリメンタル絞り込み） |
| `Tab` | サイドバー ⇔ 書籍一覧 のフォーカス切り替え |
| `Esc` | 入力欄から抜けて書籍一覧へ戻る |

**書籍一覧**

| キー | 動作 |
|---|---|
| `j` / `↓`、`k` / `↑` | 次 / 前の書籍へ移動 |
| `PageDown` / `PageUp` | 1 画面分移動 |
| `g` / `Home`、`G` / `End` | 先頭 / 末尾へ移動 |
| `h` / `←` | サイドバーへ移動 |
| `1` 〜 `5` | 選択中の書籍の★評価を 1〜5 に変更（`0` で評価クリア） |
| `Enter` or `o` | リンク（Amazon / 公式ページ）を既定ブラウザで開く |
| `e` | 感想・メモ欄の編集にフォーカス（`Ctrl + S` で保存） |
| `u` | 書誌情報を検索して更新 |
| `s` / `r` | 並び替えの項目を切り替え / 昇順・降順を反転 |
| `Delete` | 選択中の書籍を削除（確認ダイアログあり） |

**サイドバー**

| キー | 動作 |
|---|---|
| `j` / `↓`、`k` / `↑` | 絞り込み項目を移動 |
| `Enter` / `l` / `→` | 書籍一覧へ移動 |

検索バーで `Enter` または `↓` を押すと、絞り込み結果の先頭の書籍を選んで一覧へ移る。

## 3. データモデル (SQLite)

Notion からエクスポートされた CSV の全カラムと完全互換を保ち、API自動取得フィールドと感想コメント欄を追加する。

```sql
CREATE TABLE IF NOT EXISTS books (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,                     -- タイトル (CSV: タイトル)
    subtitle TEXT,                          -- サブタイトル (API取得)
    author TEXT,                            -- 著者 (CSV: 著者)
    publisher TEXT,                         -- 出版社 (API取得)
    published_date TEXT,                    -- 出版日 (API取得)
    isbn TEXT,                              -- ISBN-10 / ISBN-13 (API取得)
    status TEXT NOT NULL DEFAULT '未着手',   -- ステータス (読了, 読書中, 未着手, 積読)
    media_type TEXT NOT NULL DEFAULT '書籍', -- 種別 (書籍, オーディブル, 書籍（図書館）, Kindle Unlimited, Kindle)
    rating INTEGER DEFAULT 0,               -- 評価 (0:未評価, 1:★, 2:★★, 3:★★★, 4:★★★★, 5:★★★★★)
    started_at TEXT,                        -- 読書開始日 (YYYY-MM-DD)
    completed_at TEXT,                      -- 読了日 (YYYY-MM-DD)
    link_url TEXT,                          -- リンク (Amazon, 出版社等)
    cover_url TEXT,                         -- リモート表紙URL
    cover_local_path TEXT,                  -- ローカルキャッシュ表紙パス
    notes TEXT,                             -- 感想・メモ (数行のコメント)
    created_at TEXT NOT NULL DEFAULT (datetime('now', 'localtime')),
    updated_at TEXT NOT NULL DEFAULT (datetime('now', 'localtime'))
);

CREATE INDEX IF NOT EXISTS idx_books_status ON books(status);
CREATE INDEX IF NOT EXISTS idx_books_media_type ON books(media_type);
CREATE INDEX IF NOT EXISTS idx_books_rating ON books(rating);
CREATE INDEX IF NOT EXISTS idx_books_completed_at ON books(completed_at);
```

### Notion CSV の変換仕様
- `評価` 列: `⭐️` の文字数（0〜5）を数値 `rating` にマッピング。
- `読了日` / `開始` 列: `2024年6月16日` → `2024-06-16` に正規化。空欄は NULL。
- `リンク` 列: そのまま `link_url` に格納。
- `種別` 列: `書籍`, `オーディブル`, `書籍（図書館）`, `Kindle Unlimited` などを保持。

## 4. 書籍自動検索 & 補完仕様 (API & リンク先直接取得)

### 4.1 検索 & 補完フロー
1. **リンク先からの直接抽出 (`fetch_from_link`)**:
   - 本に `link_url`（Notion から移行した Amazon / Audible / Web 記事等の URL）がある場合、詳細画面の「🔗 リンク先から取得」ボタン、または検索ダイアログからワンクリックで書誌情報を直接取得・反映。
   - Amazon / Audible の URL: **ページは取得しない**。URL に含まれる ASIN（紙の本では ISBN-10）とタイトル部分だけを使う。ASIN から書影 URL (`https://images-na.ssl-images-amazon.com/images/P/{ASIN}.01.LZZZZZZZ.jpg`) を組み立て、ISBN が分かるときは openBD → CiNii Books で正式書名・著者・出版社・出版日を補完する。
   - 一般 Web ページ / メディア記事: ページを 1 回だけ取得し（5 MB まで）、OGP メタタグ (`og:title`, `og:image`, `og:description`, `author`) からタイトル・表紙・著者を取得。
   - すべての通信は `bookf/<バージョン>` を名乗る User-Agent で行い、ブラウザーを装わない。
2. **CiNii Books API 検索**:
   - タイトル・著者名・キーワードによる和書検索 (`https://ci.nii.ac.jp/books/opensearch/search`)。レート制限や API キー不要で膨大な日本語図書カタログを検索可能。
3. **openBD API 連携**:
   - ISBN（10桁/13桁）が特定された場合、国内出版社の公式書影・正式レーベル・詳細情報を自動マージ。
4. **Amazon リンク自動生成**:
   - ISBN-10 または ISBN-13 から `https://www.amazon.co.jp/dp/{ISBN10}` を自動生成。
5. 表紙画像をローカル（`covers/` フォルダ）に自動ダウンロード・キャッシュし、オフラインでも表示可能にする。画像は 10 MB まで、Content-Type が画像でないものは保存しない。

## 5. Google ドライブ同期 & クラウド運用設計

- **保存場所**: ユーザーが設定画面で「データベース保存先」を任意のパス（例: `G:\マイドライブ\読書記録\books.db`）に指定可能。初期値は `%APPDATA%\dev.bookf.app\books.db`。
- **WAL競合回避**: Google ドライブなどのクラウド同期ソフトと併用するため、`PRAGMA journal_mode = DELETE` を使用し、`.wal` ファイルの残留による同期競合を防ぐ。
- **自動バックアップ**: データベースを開いたとき（起動時と保存先の切り替え時）に、全書籍を `books_backup.json` としてデータベースと同じフォルダに書き出す（書籍が 0 件のときは書き出さない）。クラウド同期のコンフリクトやファイル破損のときは、直前に開いた時点の状態から復元できる。
- **保存先が開けないとき**: 設定した保存先（同期ドライブ未接続など）を開けない場合は、既定の `%APPDATA%\dev.bookf.app\books.db` を開く。
- **将来のスマホ対応**:
  - Tauri 2 Mobile（Android/iOS）にて同一コードベースからアプリビルド、または Google Drive 上のファイルを直接読み書きする軽量な Web/PWA クライアントを展開。
