## 1. 画面構成

```
+--------------------------------------------------------------------------------------------+
| ファイル(F)  編集(E)  表示(V)                                                              |  メニューバー
| 検索 [/ でタイトル・著者・感想を絞り込み        ]  並び: 読了日 降順（s で切替 / r で反転） |  検索バー
+-------------+-------------------------------------------------+----------------------------+
| 絞り込み    | 本 (212 冊)                                     | 詳細                       |
| すべて  212 | 評価   タイトル        著者     種別   状態 読了日|  [表紙]  タイトル           |
| ステータス  | ★★★★★ 具体と抽象       細谷 功  書籍   読了 2024/|          ★★★★☆             |
|  読了   198 | ★★☆☆☆ 言語沼           水野 太貴 書籍  読了 2024/|  著者 / 状態 / 種別        |

| 種別        |                                                 |  出版社 / 出版日 / ISBN    |
| 評価        |                                                 |  リンク [↗]                |
| 読了年      |                                                 |  感想・メモ                 |
+-------------+-------------------------------------------------+----------------------------+
| 1/212   全 212 冊 / 読了 198 冊   平均 ★3.8   (メッセージ)          (データベースのパス)     |  ステータスバー

```

| 領域 | 内容 |
|---|---|
| メニューバー | ファイル（本を追加・Notion CSV 取り込み・データベースを開く・保存先を移動）、編集（書誌情報を検索・リンク先から書誌情報を取得・表紙画像を変更・リンクを開く・本を削除）、表示（並び替え 4 種・昇順/降順・絞り込みの解除）。`Alt` + アクセスキーで開く。選択が無いときなど、使えない項目は無効表示。 |
| 検索バー | 空白区切りの語をすべて含む本に絞り込む。対象はタイトル・サブタイトル・著者・出版社・感想・ISBN。大文字小文字と全角半角を区別しない（NFKC）。 |
| サイドバー（幅 13.5%） | 「すべて」「ステータス」「種別」「評価」「読了年」の見出しと、各値の件数。選ぶと一覧を絞り込む。ステータスと種別は既定の順（下記）、評価は ★5 → 未評価、読了年は新しい順。 |
| 書籍一覧 | 評価・タイトル・著者・種別・状態・読了日の 6 列。列見出しで並べ替え。感想がある本はタイトルの後ろに ✎。ダブルクリックでリンクを開く。 |
| 詳細（幅 30%） | 表紙（クリックで表紙の変更）、タイトル、★評価、著者、状態、種別、開始日、読了日、出版社、出版日、ISBN、リンク（↗ で開く）、感想・メモ、登録・更新日時。各欄は変更してフォーカスを外すと保存。 |
| ステータスバー | 選択位置/表示件数、全件数と読了件数、評価済みの本の平均、メッセージ（6 秒で消える）、データベースのパス。 |

### 1.1 状態と種別

- 状態の既定の値: 読了、読書中、未着手、積読、中断。状態を「読了」にしたとき読了日が空なら今日、「読書中」にしたとき開始日が空なら今日を入れる。
- 種別の既定の値: 書籍、書籍（図書館）、Kindle、Kindle Unlimited、オーディブル、学術誌、記事。取り込んだデータにある他の値も選べる。

### 1.2 並べ替え

| 項目 | 新しく選んだときの向き | 備考 |
|---|---|---|
| 読了日 | 降順 | 読了日が無ければ開始日で比べる。どちらも無い本は向きにかかわらず最後。 |
| 評価 | 降順 | |
| タイトル・著者・種別・状態 | 昇順 | 日本語の照合順 |

同じ列をもう一度選ぶと向きを反転する。値が等しいときは登録順。

## 2. 外観

`guif` のプリセット `nord` と同じ配色。等幅フォント（JetBrains Mono → Cascadia Mono → Consolas → BIZ UDGothic）。枠は 1px の実線、角丸なし。フォーカスのある枠は `#88C0D0`。

## 3. キー操作

ダイアログを開いている間と、IME で変換中は、メイン画面のキー操作は働かない。

### 3.1 全体

| キー | 動作 |
|---|---|
| `Ctrl+N` | 本を追加（書誌情報の検索ダイアログ） |
| `Ctrl+I` | Notion CSV を取り込む |
| `Ctrl+O` | データベースを開く |
| `Ctrl+F` / `/` | 検索バーへ（`/` は入力欄の外でだけ） |
| `Tab` | サイドバー ⇔ 書籍一覧 |
| `Esc` | 入力欄から抜けて書籍一覧へ |

`Ctrl` の組み合わせは入力欄の中でも働く。それ以外のキーは、入力欄の中では文字の入力に使う。

### 3.2 検索バー

| キー | 動作 |
|---|---|
| `Enter` / `↓` | 絞り込み結果の先頭の本を選んで書籍一覧へ |

### 3.3 サイドバー

| キー | 動作 |
|---|---|
| `j` / `↓`、`k` / `↑` | 項目を移動（見出しは飛ばす）。移動すると一覧をその条件で絞り込む |
| `Enter` / `l` / `→` | 書籍一覧へ |

### 3.4 書籍一覧（詳細パネルにフォーカスがあるときも同じ）

| キー | 動作 |
|---|---|
| `j` / `↓`、`k` / `↑` | 次 / 前の本 |
| `PageDown` / `PageUp` | 1 画面分 |
| `g` / `Home`、`G` / `End` | 先頭 / 末尾 |
| `h` / `←` | サイドバーへ |
| `1`〜`5` / `0` | ★評価を付ける / 消す |
| `Enter` / `o` | リンクを既定のブラウザーで開く |
| `e` | 感想・メモの編集へ（`Ctrl+S` で保存） |
| `u` | 書誌情報を検索して更新 |
| `s` | 並べ替えの項目を順に切り替え（読了日 → タイトル → 著者 → 評価 → 種別 → 状態） |
| `r` | 昇順・降順を反転 |
| `Delete` | 本を削除（確認ダイアログ） |

### 3.5 書誌情報の検索ダイアログ

| キー | 動作 |
|---|---|
| `Enter` | 検索語が変わっていれば検索、変わっていなければ選んでいる候補で追加・更新 |
| `↑` / `↓` | 候補を移動 |
| `Esc` | 閉じる |
