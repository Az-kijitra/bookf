## 1. 文書と読者

| 文書 | 読者 | 内容 |
|---|---|---|
| `README.md` | GitHub を訪れた人 | 概要、インストール、主な特徴、主なキー、データの保存場所、取得元、アンインストール、文書へのリンク |
| `docs/user_manual.md` | 利用者 | すべての操作、全キー、同期フォルダーでの運用、バックアップからの復元、困ったとき |
| `CHANGELOG.md` | 利用者・開発者 | 版ごとの変更 |
| `specs/` | 開発者 | 仕様（台帳 `_registry.md`、決定と課題 `_issues.md`） |

文言は日本語。画面の文言（メニュー名・ボタン名）は画面と同じ表記で書く。

## 2. 整合の約束

次は Vitest（`app/src/release.test.ts`）で検査する。

- `CHANGELOG.md` に今の版（`tauri.conf.json` の `version`）の節 `## <version>` がある。
- `README.md` と `docs/user_manual.md` に、今の版のインストーラー名 `bookf_<version>_x64-setup.exe` が書かれている。
- `docs/user_manual.md` の 1 行目（題名）に `(<version>)` がある。

次は手で確認する。

- キー操作を変えたら、SPEC-0300-0001 §3、マニュアル §6、README のキー表をそろえる。
- 取得元や通信の方針を変えたら、SPEC-0300-0003、README の「データの取得元」、マニュアル §5 をそろえる。
